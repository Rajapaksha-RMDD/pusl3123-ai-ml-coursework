# CIFAR-10 Image Classification (Assessment 1)

This repository contains the implementation, training, and evaluation of neural network models for image classification using the CIFAR-10 dataset. The project investigates Multi-Layer Perceptrons (MLP), Convolutional Neural Networks (CNN), regularisation techniques, and model complexity.

## Project Structure
* `Exercise_1_MLP.ipynb`: Implementation and training of a 3-layer Multi-Layer Perceptron.
* `Exercise_2_CNN.ipynb`: (Pending) Implementation of a 3-layer Convolutional Neural Network.
* `Exercise_3_Regularisation.ipynb`: (Pending) Evaluation of dropout and data augmentation.
* `Exercise_4_Complexity.ipynb`: (Pending) Analysis of network width and depth variations.

## Dependencies
To execute these notebooks, the following libraries are required:
* Python 3.x
* PyTorch (`torch`, `torch.nn`, `torch.optim`)
* Torchvision (`torchvision`, `torchvision.transforms`)
* Matplotlib (`matplotlib.pyplot`)

## Execution Instructions
1. Open the Jupyter Notebooks in Google Colab or a local Jupyter environment.
2. Ensure a GPU is enabled for faster training (In Colab: `Runtime` > `Change runtime type` > `T4 GPU`).
3. Run the cells in sequential order. The CIFAR-10 dataset partitions (50,000 training images, 10,000 test images) will download automatically during the initial execution.
